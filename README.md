# Radar Judicial · Alttura Lex

Buscador de procesos judiciales de Colombia para Windows. Escribes el número de radicación (23 dígitos) o el nombre de una de las partes y ves en una sola pantalla en qué va el proceso, el último auto, el último estado (con el enlace al estado electrónico), las audiencias y todas las actuaciones. Con «Mis procesos» guardas procesos y revisas con un clic si tienen actuaciones nuevas.

Los datos se consultan en vivo en la Consulta de Procesos Nacional Unificada de la Rama Judicial. La consulta es informativa: no reemplaza la revisión del expediente ni la notificación por estado.

## Descargar

1. Entra a **[Releases](../../releases/latest)** y descarga `RadarJudicial.exe`.
2. Haz doble clic. Se abre el navegador con el buscador.
3. La primera vez Windows puede decir que el programa es de un «editor desconocido»: haz clic en **Más información** y luego en **Ejecutar de todas formas**.
4. Para cerrarlo, cierra la ventana negra.

No necesita instalación. «Mis procesos» queda guardado en tu computador (`%LOCALAPPDATA%\RadarJudicial`) y no se pierde al descargar una versión nueva. Cuando haya una versión nueva, el programa lo avisa.

Este repositorio solo publica las descargas.
